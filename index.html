📖 À propos

Cette API REST simulée fournit des données de projets web pour l'apprentissage des requêtes AJAX en JavaScript.

Base URL: https://VOTRE-USERNAME.github.io/webcraft-api
Format: JSON
CORS: Activé
Authentification: Non requise

🔌 Endpoints disponibles

📁 Projects API

GET /data/projects.json

Récupère tous les projets web (8 projets disponibles)

GET ?technology={tech}

Filtrer les projets par technologie (filtrage côté client)

Exemple: Filtrer les projets React

GET ?category={category}

Filtrer les projets par catégorie (filtrage côté client)

Exemple: Filtrer les projets E-commerce

🎓 Courses API

GET /data/courses.json

Récupère tous les cours de formation (10 cours disponibles)

GET ?category={category}

Filtrer les cours par catégorie (filtrage côté client)

Exemple: Filtrer les cours Frontend

GET ?level={level}

Filtrer les cours par niveau (filtrage côté client)

Exemple: Filtrer les cours Débutant

💻 Exemples de code

Avec Fetch API

// Charger tous les projets
async function loadProjects() {
    try {
        const response = await fetch('https://VOTRE-USERNAME.github.io/webcraft-api/data/projects.json');
        
        if (!response.ok) {
            throw new Error(`Erreur HTTP: ${response.status}`);
        }
        
        const data = await response.json();
        console.log('Projets:', data.projects);
        
        // Afficher les projets
        displayProjects(data.projects);
        
    } catch (error) {
        console.error('Erreur de chargement:', error);
    }
}

Avec Axios

// Charger tous les projets avec Axios
async function loadProjects() {
    try {
        const response = await axios.get('https://VOTRE-USERNAME.github.io/webcraft-api/data/projects.json');
        
        console.log('Projets:', response.data.projects);
        displayProjects(response.data.projects);
        
    } catch (error) {
        console.error('Erreur:', error.message);
    }
}

Filtrer par technologie

// Filtrer les projets React côté client
async function loadReactProjects() {
    try {
        const response = await fetch('https://VOTRE-USERNAME.github.io/webcraft-api/data/projects.json');
        const data = await response.json();
        
        // Filtrer les projets contenant React
        const reactProjects = data.projects.filter(project => 
            project.technologies.includes('React')
        );
        
        console.log('Projets React:', reactProjects);
        displayProjects(reactProjects);
        
    } catch (error) {
        console.error('Erreur:', error);
    }
}
